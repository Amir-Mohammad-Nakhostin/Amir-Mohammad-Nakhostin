# Sansino

**Sports facility booking · Software product development**

Sansino is a sports facility reservation platform designed around finding available sessions, making reservations and supporting facility management.

- Product focus: a streamlined sports facility booking experience.
- Engineering focus: reservation workflows, availability management and full-stack web development.
- Status: beta-stage development.
- Project website: [sansinoapp.ir](https://sansinoapp.ir).

The source repository is private. This public overview does not claim verified production availability or disclose implementation details.
